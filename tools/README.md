# 影片處理腳本使用說明

主辦方收到學生影片後，在自己的電腦上執行這支腳本：檢查影片 → 轉成網頁播放版 → 更新影片清單。
需要 Python 3 與 ffmpeg（`ffmpeg -version` 能執行）。

## 一、放影片

把學生交來的檔案放進專案資料夾的 `影片原檔/`，**依規則改檔名**：

| 情況 | 檔名 |
|---|---|
| 第 1 組第一次交件 | `team01_v1.mov`（或 `.mp4`） |
| 第 1 組補件 | `team01_v2.mov`（版本號加 1，**不要覆蓋舊檔**） |

`影片原檔/` 不會被推上 GitHub（已列在 .gitignore）。

## 二、執行

在專案資料夾執行：

```
python tools/process_videos.py
```

| 選項 | 用途 |
|---|---|
| `--check-only` | 只檢查，不轉檔、不改清單（先看看有沒有不合格的） |
| `--only team01` | 只處理某一組 |
| `--no-limits` | 測試模式：超過 500 MB 或 10:00 不擋，照樣轉檔，清單註記「測試模式未擋」。很長的影片會自動改成 480p、降低碼率，播放版仍控制在 95 MB 內（60 分鐘以上畫質會明顯變差）。正式比賽不要用 |

轉檔時間大約是影片長度的 0.5～1 倍（10 分鐘影片約 5～10 分鐘，依電腦速度而定）。中途中斷沒關係，已處理完的會記在清單裡，重跑會從沒處理的繼續。

## 三、看報告

| 結果 | 意思 | 要做什麼 |
|---|---|---|
| 完成 | 檢查合格、已產生播放版 | 無 |
| 不合格 | 檢查沒過（原因寫在後面） | 通知該組重交，存成下一個版本號 |
| 略過 | 已經處理過，或檔名不符規則 | 檔名不符的請改名 |
| 錯誤 | 同一個版本號換了不同的檔案 | 補件請用新的版本號 |

**檢查項目**：實際格式是 MP4／MOV、有影像也有聲音、長度不超過 10:00（剛好 10:00 可以）、原檔不超過 500 MB、整支影片可以完整解碼。

**播放版**：H.264＋AAC 的 MP4，短邊 720（直式影片自動轉正）、保留原本的播放速度與音畫同步，大小一定在 95 MB 以內（GitHub 單檔上限 100 MB）。

## 四、推上網站並同步

1. 確認報告沒問題後推送（推送等於公開發布）：

   ```
   git add docs/videos
   git commit -m "新增影片：team01_v1、team02_v1"
   git push
   ```

2. 等 1～2 分鐘網站更新，到後台按「**同步影片清單**」，新版本就會出現在作品頁。

## 測試

`python test/test_videos.py`：用合成測試片驗證全部檢查規則、直式影片、音畫同步與碼率上限（約 5 分鐘）。
