# 台股新聞彙整儀表板

把 `data/digest.md`（每輪更新的台股新聞彙整）轉成單一靜態網頁 `index.html`。

## 使用
```
python3 stock-news/build.py   # 重新產生 index.html，只需 Python 標準函式庫
```
更新時，把新的 md 覆蓋到 `data/digest.md` 再執行上面的指令即可。

## 功能
- 日期重點可摺疊，最新一輪以紫色標示
- 表格點表頭排序（數字欄依數值）
- 上方搜尋框可搜代號、公司、關鍵字，並標示命中處
- 深色／淺色切換，手機版可閱讀

## K 線圖
股價資料放在 `data/prices/<代號>.json`，由 `fetch_prices.py` 產生（證交所會擋雲端主機，請在自己的電腦執行）：
```
python3 stock-news/fetch_prices.py 6213 1303 --months 6
python3 stock-news/build.py
```
圖表為紅漲綠跌，含 MA5/20/60、成交量、滑鼠十字線與近 20 日數據表。目前只支援上市股票；沒有資料時頁面顯示操作提示。

## 已知限制
- 原稿的「焦點股 9 月營收」表沒有資料列，頁面會標示為空
- 均線沒有做除權息還原；上櫃股（櫃買中心）尚未支援
- 數字皆引自媒體報導，目標價與預估為法人觀點，不構成買賣建議
